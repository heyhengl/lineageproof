The delivery

A small pipeline with an acceptance boundary.

01

Validate the payload contract

Reject unmarked or malformed fixtures before any comparison result is produced.

02

Normalize one provider

Map provider, SKU, region, operating system, price type, currency, unit and hourly price into stable keys.

03

Compare two snapshots

Separate new, removed, price-changed and unchanged keys while surfacing duplicates and invalid rows.

04

Freeze the review receipt

Return current-snapshot CSV, changes CSV, SQLite tables, summary JSON and deterministic content hashes.
