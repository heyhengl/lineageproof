Freeze the receipt first

Compilation proves reproducibility—not intent.

The compiler can show that one exact source tree produced one binary under one recorded environment. A manifest can fingerprint the source, preset, binary, log and checks. Neither can prove that the implemented rules are the buyer's intended rules or that a strategy will make money.

Containment before execution

A safe default must exist twice.

The source declares trading disabled, and the supplied preset repeats the same default. The audit checks both so installation and state inspection do not automatically authorize an order path.

  1. 01
    Source gate

    Keep execution disabled unless one explicit input is enabled.

  2. 02
    Preset gate

    Ship the review preset with the same default-off state.

  3. 03
    Gateway

    Confine direct trade calls to one reviewable executor module.

    Receipt

    Reconcile the exact source, preset, binary, compiler log and hashes.

Five gates after compile

A clean build still leaves five acceptance decisions.

  • Rule gate: indicators, timeframes, closed-bar rules, thresholds, precedence and refresh triggers.
  • Environment gate: terminal build, MetaEditor build, symbol suffixes and tester-data coverage.
  • State gate: initialization, missing data, partial history, changed symbols and unchanged-bar refresh.
  • Execution gate: permission, volume normalization, stops, fill modes and failure responses.
  • Handoff gate: source, preset, binary, logs, hashes, installation notes and unresolved REVIEW items.
