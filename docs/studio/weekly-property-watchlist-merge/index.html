The delivery

A repeatable weekly update, not a fragile one-off dedupe.

01

Stable-key check

Confirm a listing ID or another agreed key that does not change when the days-on-market field advances.

02

Note carry-forward

Bring the previous visit note onto the current row when the current export has no new note.

03

Current-note override

Use the new note when staff add an update, while keeping the prior note visible for audit.

04

Exception queue

Hold missing and duplicate IDs for review instead of guessing, dropping a row or attaching a note to the wrong property.

05

Refresh guide

Return the merged workbook, change log and short instructions for the next weekly update.
